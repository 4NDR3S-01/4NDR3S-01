<p>
¡Hola! Soy <b>Andrés</b> 👋, desarrollador <b>Full Stack</b> de Ecuador 🇪🇨.
Me interesa toda el área de la programación y disfruto convertir ideas en aplicaciones
reales: plataformas web, apps móviles y herramientas que usan <b>inteligencia artificial</b>
para resolver problemas concretos. También me apasionan la <b>ciberseguridad</b> 🔐 y las
<b>redes</b> 🌐: entender cómo funcionan los sistemas por dentro y cómo protegerlos.
</p>

<p>
Muchos de mis proyectos nacen de una necesidad cercana: estudiar mejor, gestionar procesos
académicos o cuidar la salud. Me gusta llevarlos de principio a fin, desde el diseño de la
base de datos hasta la interfaz y el despliegue.
</p>

<b>🚀 Actualmente trabajando con:</b>

<ul>
  <li><b>Frontend</b> — Next.js, React, TypeScript, PHP y Tailwind CSS</li>
  <li><b>Mobile</b> — React Native + Expo y Kotlin</li>
  <li><b>Backend</b> — NestJS, Prisma y APIs REST</li>
  <li><b>Datos</b> — PostgreSQL, MongoDB, CouchDB y MySQL / MariaDB</li>
  <li><b>IA</b> — integración de modelos de lenguaje en apps educativas y de salud</li>
</ul>

<p>
💞️ Siempre abierto a <b>colaborar en proyectos</b> para seguir aprendiendo y ganando experiencia.
</p>
